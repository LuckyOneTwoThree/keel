## 条目格式参考

```yaml
---
id: DEP-0001
type: dep
title: 一句话依赖描述
date: 2026-07-25
status: 等待中            # 等待中 / 已就绪 / 已逾期
partner: 合约审计团队      # 依赖方(引用干系人矩阵或裸字符串)
expected_delivery: 2026-08-15   # 期望交付日(ISO)
blocks: [REQ-0001]        # 阻塞哪些条目
related: []
related_external: [合约审计团队]
draft: false
---
```

```markdown
### DEP-0001 — 2026-07-25
一句话依赖描述

(散文:交付内容 / 验收标准 / 跟进动作)
```
