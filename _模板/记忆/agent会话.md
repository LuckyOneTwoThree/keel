# agent 会话 (SESSION-)

> v3.0 §2.5 · 短时记忆。跨会话延续 agent 工作流状态。
> append-only。月度分片(超 200 行或 50 条时滚入 `记忆/归档/agent会话-YYYY-MM.md`)。
>
> **边界判据**(只记工作流,不记项目事):
> - ✅ 工作流:能写成"下一步: X"被直接消费的(如"卡在:验收标准未定,等 PM 给清单")
> - ✗ 项目事:只是背景描述的(如"用户说想要双因子认证" → 该记 COM- 或 REQ 描述)
>
> 判据:能被"下一步"直接消费 = 工作流;只是背景 = 项目事。

## 条目格式参考

```yaml
---
id: SESSION-2026-07-25-1430
type: session
title: 一句话会话目标
date: 2026-07-25
status: 进行中            # 进行中 / 已结束 / 已中断
draft: false
---
```

```markdown
### SESSION-2026-07-25-1430
一句话会话目标

- **目标**: 本次会话要达成什么
- **已做**: 关键动作(读了 X / 写了 Y / 校验了 Z)
- **卡在**: 当前阻塞(可被下次会话消费)
- **下一步**: 直接动作清单
```
