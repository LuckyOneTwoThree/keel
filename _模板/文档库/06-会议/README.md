# 06-会议 目录

> 设计方案 v3.0 §七 标 **deferred**:不预建模板,现写现用。
> 拉动条件:会议纪要频次高到需要统一模板时,再建 `_模板.md`。

## 命名规范

`YYYY-MM-DD-会议-{主题}.md`

## 写法脚手架(deferred 期间现写现用)

会议纪要正文,无 frontmatter(非条目,非 doc 文件)。直接复制以下结构填写:

```markdown
# YYYY-MM-DD 会议 — {主题}

> 时间: YYYY-MM-DD HH:MM ~ HH:MM
> 地点/链接: (会议室或会议链接)

## 参会人

- (姓名/角色) — (参会/请假/列席)

## 议题

1. (议题 1)
2. (议题 2)

## 讨论

### 议题 1: (标题)
- (要点)

## 决议

- (决议 1) — 引 DEC-XXXX
- (决议 2) — 引 DEC-XXXX

## 行动项

| 行动 | 责任人 | 截止 | 关联 |
| --- | --- | --- | --- |
| | | | PRG-/DEC-/RSK- |
```

## 域边界速记

- 正式决议 → 追加 DEC- 条目(决策记录.md)
- 沟通结论/表态 → 追加 COM- 条目(沟通记录.md)
- 行动项进展 → 追加 PRG- 条目(进度日志.md)
- 本文件仅记会议本身(讨论过程 + 决议摘要 + 行动项指派)
