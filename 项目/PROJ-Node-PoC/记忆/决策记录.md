### DEC-0005 — 2026-07-09
Node 产品形态独立与边界确认

原"IM开放服务生态矩阵"含 IM App/福利中心/保险库/统一后台等多个模块,边界模糊。需明确 Node 产品的最终形态,为后续开发与新功能(如 Aeon R9 链上关系)集成提供基准。

采用方案 B:Node = 纯 Web3 自管钱包 App(冷钱包舱 + 服务舱:福利特权/保险库/DID 通行证),保留服务管理后台作为 B 端配套。IM 聊天通讯 App、IM 开放服务统一后台剥离为外部独立应用。

理由:Node 聚焦 Web3 自管钱包与数字通行证核心能力,IM 通讯与统一后台属于不同业务域;服务管理后台是 Node 运营的必要配置工具,需保留。

影响:起草 PRD-Node产品总纲 作为产品顶层 PRD;新建 Node 公共框架 HTML 原型;福利特权保留 3 个模块(空投/资产/互动);历史文档(IM 统一后台 PRD/验收文档等)由 PM 后续清理,需保留演变路线记录。
