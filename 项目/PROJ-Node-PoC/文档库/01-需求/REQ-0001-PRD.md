# REQ-0001-PRD Node 产品总纲

> 条目级元信息见 [需求登记册](../../项目管理/需求登记册.md) REQ-0001。

## 1. 产品定位

Node = 纯 Web3 自管钱包 App(C 端) + 服务管理后台(B 端配套)。从原"IM开放服务生态矩阵"独立剥离。

## 2. 产品形态

- **C 端 App**:冷钱包舱 + 服务舱(福利特权 3 模块 + 保险库 + 数字身份通行证 + DApp 探索)
- **B 端配套**:服务管理后台
- **已剥离**:IM 聊天通讯 App、IM 开放服务统一后台

## 3. 第 5 章 交易/商城(现行有效设计)

以"统一商品池 + 级差返利"为准,取代已归档的 v2.0 层级化代理商城体系(DEC-0007/0008/0009)。
